## 硬性规则（你再派的子代理也必须把本节原样写进它的指令）

- 禁止用 git 回滚：不准用 reset、restore、revert、clean、stash、checkout -- 等命令。需要恢复时，用文件编辑工具手动改回。切换分支用 `git switch`。
- 禁止读写 /tmp 和 /private/tmp。中间结果、日志、截图放在 `【仓库路径】/.scratch/` 下（该目录已写进 .gitignore）。
- 只用文件编辑工具创建和修改文件，不用 heredoc、sed、perl 或脚本批量改代码。
- 不修改本次任务范围以外的文件（包括 .gitignore）。
- 不 commit、不 push、不开自动合并，除非本指令明确要求。
- 命令成功与否只看退出码。门禁用 `bash scripts/run-gate.sh verify` 运行，只认最后一行的 `REAL_EXIT=`；不接 `| tail`、`| head` 之类的管道再判断。
- 你如果再派子代理，必须把本节硬性规则原样写进它的指令。
